# Oil Spill Attribution System

AI-powered detection and attribution of marine oil spills using satellite
imagery, oceanographic data and AIS vessel trajectories.

## Problem

Marine oil spills can cause significant environmental damage while the vessel
responsible may remain unidentified.

This project aims to:

```text
Detect oil spill
      ↓
Measure and characterize spill
      ↓
Estimate probable origin and time
      ↓
Reconstruct relevant vessel traffic
      ↓
Rank likely responsible vessels
      ↓
Present evidence through GIS dashboard
